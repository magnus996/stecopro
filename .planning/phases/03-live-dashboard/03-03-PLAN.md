Import additional drizzle helpers as needed (`lte, gt, gte, lt, desc, asc, isNull, or, sql`) from 'drizzle-orm', the new tables (`shifts, stopEvents, baleEvents, machines, timeSeriesReadings, fractions`) from '@/db/schema', and `getShiftType, getShiftBoundsUtc` from './time'.

TIMESTAMP RULE (critical — see RESEARCH Pitfall 3): Drizzle `integer({mode:'timestamp'})` over better-sqlite3 stores/returns Unix SECONDS as JS Date objects. When comparing against a JS Date in a WHERE clause, pass a `new Date(...)` (Drizzle serialises it correctly). When you need "now", use `new Date()`. Do NOT mix raw ms numbers into Date columns.

Add these accessors (plantId is a normal arg — only tenantId is forbidden as a param):

1. `getCurrentShiftForPlant(plantId)` — the shift row whose [startAt, endAt) covers now; returns the row or null (null = outside shift). Use `lte(shifts.startAt, now)` and `gt(shifts.endAt, now)`, scoped by tenant + plant, limit 1.

2. `getRecentStops(plantId, limit = 8)` — latest stop rows ordered by `desc(stopEvents.startAt)`, scoped by tenant + plant. Return startAt, endAt, reason, stopType. Caller computes duration (endAt ?? now) - startAt.

3. `getLatestBunkerReadingState(plantId)` — find the machine with `type='bunker'` for this plant/tenant, then the single latest `timeSeriesReadings` row for that machine (`desc(recordedAt) limit 1`); return `{ recordedAt, currentA, runState }` or null. Used for freshness + empty detection.

4. `getOpenStop(plantId)` — the most recent stop with `isNull(stopEvents.endAt)` ordered by `desc(startAt)`, scoped, limit 1; returns the open stop or null. Used to derive running/stopped/running-empty (an open stop with reason 'Bunker tom' / stopType 'idle' => running-empty).

5. `getShiftStops(plantId, shiftStart, shiftEnd)` — stops overlapping the window: `lt(stopEvents.startAt, shiftEnd)` AND `or(isNull(stopEvents.endAt), gt(stopEvents.endAt, shiftStart))`, scoped by tenant + plant. Returns startAt, endAt, stopType, reason. Feeds calculateOee.

Each function returns plain rows (Date objects are fine here — the PAGE will serialise before passing to client components; DAL stays server-side).

   - openStop = await getOpenStop(plantId)
   - latestBunker = await getLatestBunkerReadingState(plantId)
   - Derive plant state (string enum) per RESEARCH Pattern 5 ordering:

     b) else if getShiftType(now.getTime()) is null => `'outside_shift'`.
     c) else if openStop exists: if openStop.stopType === 'idle' (reason 'Bunker tom') => `'running_empty'`; else => `'stopped'` (carry openStop.reason).
     d) else => `'running'`.
   - OEE for current shift: if shift, gather getShiftStops(plantId, shift.startAt, shift.endAt) and the current-shift bale count (sum across fractions in the shift window), then call `calculateOee({ shiftStart: shift.startAt, shiftEnd: shift.endAt, nowMs: now.getTime(), stopEvents, baleCount, nominalBalesPerShift: NOMINAL_BALES_PER_SHIFT })`. If no shift, OEE = null. Define `NOMINAL_BALES_PER_SHIFT = 120` locally with a comment referencing params.ts BALE_RATES_PER_SHIFT (45+35+25+15=120); import is not required since params.ts is simulator-side, but cite it in the comment.
   - uptime: from the same OEE result use runSeconds/plannedSeconds for the current shift. For "today" uptime, call getShiftStops over [todayStart, now] and compute run/planned with calculateOee or a small inline run-vs-planned (reuse calculateOee with baleCount/nominal set so only availability matters — or expose runSeconds/plannedSeconds). Prefer calling calculateOee for today's window too so the math is shared.
   - throughput vs nominal: `nominalCapacityTph` from the plant row (already in plants table). Compute a simple indicator = currentShiftBaleCount vs expected bales-so-far (nominal scaled by elapsed shift fraction). Return both the plant nominalCapacityTph and the computed ratio so the UI can render "Kapasitetsutnyttelse".
   - baleCounts: `currentShift` (window = shift or empty array when outside shift) and `today` (window = [todayStart, now]), each from getBaleCountsByFraction.
   - currentDraw: getBunkerCurrentDraw over the current-shift window, or last 120 min if outside shift (cutoff = now - 120*60s).
   - Return one SERIALIZABLE-friendly object, but keep Date objects here (the page converts). Include: `plant {id,name,nominalCapacityTph}`, `state`, `openStopReason`, `oee` (the OeeResult or null), `todayUptime {runSeconds, plannedSeconds}`, `baleCounts {currentShift[], today[]}`, `recentStops[]` (from getRecentStops, include endAt for duration calc), `currentDraw[]`, `latestReadingAt`, `now`, `shift` (start/end/type or null), `throughput {nominalCapacityTph, expectedBalesSoFar, actualBalesSoFar}`.
