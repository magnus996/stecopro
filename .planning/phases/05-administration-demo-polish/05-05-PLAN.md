Create src/actions/tenants.ts with `'use server'`. Imports: z from 'zod'; revalidatePath from 'next/cache'; redirect from 'next/navigation'; verifySession from '@/lib/dal'; db from '@/db'; tenants, plants from '@/db/schema'; eq from 'drizzle-orm'.

GATE pattern (both actions): `const session = await verifySession(); if (session.role !== 'system_admin') return { errors: { _: ['Ikke tilgang'] } }`. This MUST come before any use of form-supplied tenantId (RESEARCH Pitfall 1).

Schemas:
- `const CreateTenantSchema = z.object({ name: z.string().min(1), slug: z.string().min(1).regex(/^[a-z0-9-]+$/, 'Kun små bokstaver, tall og bindestrek') })`.
- `const CreatePlantSchema = z.object({ tenantId: z.coerce.number().int().positive(), name: z.string().min(1), description: z.string().optional(), nominalCapacityTph: z.coerce.number().positive().optional() })`.

Export `async function createTenant(prevState, formData)`:
1. system_admin gate.
2. parsed = CreateTenantSchema.safeParse(Object.fromEntries(formData)); on failure return errors.
3. Duplicate slug guard: select tenant by `eq(tenants.slug, parsed.data.slug)`; if exists return `{ errors: { slug: ['Slug er allerede i bruk'] } }` (slug has a unique index).
4. db.insert(tenants).values({ name, slug, createdAt: new Date() }).
5. revalidatePath('/admin/tenants'); redirect('/admin/tenants').

Export `async function createPlantForTenant(prevState, formData)`:
1. system_admin gate (BEFORE reading tenantId).
2. parsed = CreatePlantSchema.safeParse(...); on failure return errors.
3. Verify the target tenant exists: select tenant by `eq(tenants.id, parsed.data.tenantId)`; if not found return `{ errors: { _: ['Tenant finnes ikke'] } }`.
4. db.insert(plants).values({ tenantId: parsed.data.tenantId, name, description, nominalCapacityTph, createdAt: new Date() }). This is the ONE place a tenantId comes from the form — justified by the system_admin gate above. Add a comment marking it.
5. revalidatePath(`/admin/tenants/${parsed.data.tenantId}`); revalidatePath('/admin/tenants'); redirect(`/admin/tenants/${parsed.data.tenantId}`).
