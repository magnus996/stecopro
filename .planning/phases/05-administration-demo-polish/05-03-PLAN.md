  <name>Task 1: updatePlantConfig server action (role-gated, tenant-scoped)</name>
  <files>src/actions/plant.ts</files>
  <action>
Create src/actions/plant.ts with `'use server'` at the top. Follow the auth.ts action pattern (zod parse → return {errors} on failure → mutate → revalidatePath → return {success:true}). Use `verifySession` from '@/lib/dal', `db` from '@/db', tables from '@/db/schema', `revalidatePath` from 'next/cache', and zod.

Export `async function updatePlantConfig(prevState: unknown, formData: FormData)`:
1. const session = await verifySession(). ROLE GATE: if `session.role === 'operator'` return `{ errors: { _: ['Ikke tilgang'] } }`. (produksjonsleder, admin, system_admin allowed.)
2. Parse the plantId from formData (Number). The form submits the plant's own fields plus repeated fraction/machine fields keyed by id.
3. Validate plant fields with zod: name (min 1), description (optional string), nominalCapacityTph (coerce to number, positive, optional/nullable — allow empty → null). Return flattened fieldErrors on failure.
4. UPDATE plants SET name, description, nominalCapacityTph WHERE `and(eq(plants.id, plantId), eq(plants.tenantId, session.tenantId))`. The tenant scope is the security boundary — even though plantId comes from the form, the WHERE clause prevents touching another tenant's plant (RESEARCH Pitfall 1).
5. Fractions: the form sends arrays. Read `formData.getAll('fractionId')`, `getAll('fractionName')`, `getAll('fractionSortOrder')` (parallel arrays). For each, UPDATE fractions SET name, sortOrder WHERE `and(eq(fractions.id, id), eq(fractions.tenantId, session.tenantId))`. Skip rows with empty name.
6. Machines: same approach with `machineId`, `machineName`, `machineCurrentA` (do NOT touch machine `type`). UPDATE machines SET name, nominalCurrentA WHERE `and(eq(machines.id, id), eq(machines.tenantId, session.tenantId))`.
7. `revalidatePath('/admin/plant')` then return `{ success: true }`.

Keep all UPDATEs inside the session.tenantId scope. Do NOT accept tenantId from the form.
  </action>
