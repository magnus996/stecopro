Create src/actions/users.ts with `'use server'`. Imports: bcrypt from 'bcryptjs'; z from 'zod'; revalidatePath from 'next/cache'; verifySession from '@/lib/dal'; db from '@/db'; users from '@/db/schema'; eq, and from 'drizzle-orm'.

Helper: `function requireAdmin(session)` — if `!['admin','system_admin'].includes(session.role)` it returns the forbidden error object; otherwise null. (Inline the check if cleaner.)

Schemas:
- `const CreateUserSchema = z.object({ email: z.email(), name: z.string().min(1), role: z.enum(['operator','produksjonsleder','admin']), password: z.string().min(8) })` — role enum deliberately EXCLUDES system_admin (RESEARCH Pitfall 2).
- `const UpdateUserSchema = z.object({ name: z.string().min(1), role: z.enum(['operator','produksjonsleder','admin']) })`.

Export `async function createUser(prevState, formData)`:
1. session = await verifySession(); if not admin+ return `{ errors: { _: ['Ikke tilgang'] } }`.
2. parsed = CreateUserSchema.safeParse(Object.fromEntries(formData)); on failure return `{ errors: parsed.error.flatten().fieldErrors }`.
3. Guard duplicate email: select user by `eq(users.email, parsed.data.email)`; if exists return `{ errors: { email: ['E-post er allerede i bruk'] } }` (email has a unique index — avoid a raw constraint crash).
4. passwordHash = await bcrypt.hash(parsed.data.password, 10).
5. db.insert(users).values({ email, name, role, passwordHash, tenantId: session.tenantId, active: true, createdAt: new Date() }). tenantId ALWAYS from session — never from form (RESEARCH Pitfall 1).
6. revalidatePath('/admin/users'). Then `redirect('/admin/users')` (import redirect from 'next/navigation') so the user lands back on the list. (redirect throws, so no explicit return needed after it.)

Export `async function updateUser(prevState, formData)`:
1. session + admin gate.
2. userId = Number(formData.get('userId')).
3. parsed = UpdateUserSchema.safeParse(...); on failure return errors.
4. db.update(users).set({ name, role }).where(`and(eq(users.id, userId), eq(users.tenantId, session.tenantId))`). Tenant scope is the boundary.
5. revalidatePath('/admin/users'); redirect('/admin/users').

Export `async function deactivateUser(prevState, formData)`:
1. session + admin gate.
2. userId = Number(formData.get('userId')).
3. db.update(users).set({ active: false }).where(`and(eq(users.id, userId), eq(users.tenantId, session.tenantId))`).
4. revalidatePath('/admin/users'); return `{ success: true }`.
(Note in a comment: deactivation does not kill an existing 7-day JWT session immediately; getCurrentUser checks active=true so the user is bounced to /login on next navigation — RESEARCH Pattern 3, acceptable demo limitation.)

Optionally add `reactivateUser` mirroring deactivate (set active:true) for demo convenience.
