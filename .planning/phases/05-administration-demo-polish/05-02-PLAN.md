Append a new clearly-delimited "Admin accessors — Phase 5" section to dal.ts (after the Phase 4 accessors). Follow the existing patterns exactly: every accessor wrapped in `cache(async () => {...})`, calls `verifySession()` first, and the tenant-scoped ones use `eq(<table>.tenantId, session.tenantId)`.

Add and export these accessors + types:

1. `export interface AdminUserRow { id: number; name: string; email: string; role: UserRole; active: boolean; createdAt: Date }`
   Import `UserRole` type — it's already available via `@/db/schema` (add to existing import) or re-export. Use the schema's UserRole.

2. `export const getUsersForTenant = cache(async (): Promise<AdminUserRow[]> => {...})`
   - verifySession(); if `!['admin','system_admin'].includes(session.role)` throw new Error('Forbidden').
   - select id,name,email,role,active,createdAt from users WHERE `eq(users.tenantId, session.tenantId)` ordered by asc(users.name).
   - NOTE: scoped to session.tenantId even for system_admin — on /admin/users the system_admin manages their own tenant (Steco). Cross-tenant user mgmt is out of scope (documented decision).

3. `export const getUserById = cache(async (userId: number): Promise<AdminUserRow | null> => {...})`
   - verifySession(); role gate same as above.
   - select the same columns WHERE `and(eq(users.id, userId), eq(users.tenantId, session.tenantId))` limit 1. Return row ?? null. (Tenant scope prevents cross-tenant edit — RESEARCH Pitfall 5/6.)

4. `export interface PlantConfig { plant: { id:number; name:string; description:string|null; nominalCapacityTph:number|null }; fractions: { id:number; name:string; sortOrder:number }[]; machines: { id:number; name:string; type:string; nominalCurrentA:number|null }[] }`

5. `export const getPlantConfig = cache(async (plantId: number): Promise<PlantConfig | null> => {...})`
   - verifySession(); if `session.role === 'operator'` throw new Error('Forbidden') (plant config is produksjonsleder+).
   - Fetch the plant WHERE `and(eq(plants.id, plantId), eq(plants.tenantId, session.tenantId))` limit 1; return null if not found.
   - Fetch fractions (id,name,sortOrder) WHERE tenantId+plantId ordered by sortOrder asc.
   - Fetch machines (id,name,type,nominalCurrentA) WHERE tenantId+plantId ordered by asc(machines.id).
   - Return { plant, fractions, machines }.

Reuse the already-imported drizzle helpers (eq, and, asc, desc) and tables. Do not add a tenantId parameter to any of these.
