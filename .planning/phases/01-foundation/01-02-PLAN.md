<task type="auto">
  <name>Task 1: Define the full tenant-scoped schema</name>
  <files>src/db/schema.ts</files>
  <action>
Create `src/db/schema.ts` with all entity tables from SIMU-01. Use the exact schema from research section "Full Database Schema (SIMU-01)" (01-RESEARCH.md lines ~396–497). Required tables, each (except tenants) carrying a NOT NULL `tenantId` that references `tenants.id`:

- `tenants` (id, name, slug unique, createdAt)
- `users` (id, tenantId, email unique, passwordHash, name, role, active default true, createdAt) — role is text typed as 'operator' | 'produksjonsleder' | 'admin' | 'system_admin'
- `plants` (id, tenantId, name, description, nominalCapacityTph, createdAt)
- `machines` (id, tenantId, plantId, name, type, nominalCurrentA, createdAt)
- `fractions` (id, tenantId, plantId, name, sortOrder)
- `shifts` (id, tenantId, plantId, shiftType, startAt, endAt)
- `baleEvents` (id, tenantId, plantId, fractionId, machineId nullable, occurredAt, weightKg)
- `stopEvents` (id, tenantId, plantId, startAt, endAt nullable, reason, stopType 'fault'|'idle'|'planned')
- `timeSeriesReadings` (id, tenantId, machineId, recordedAt, currentA, runState boolean)

Use `integer({ mode: 'timestamp' })` for all timestamps and `integer({ mode: 'boolean' })` for booleans (SQLite has no native types — this keeps the schema Postgres-portable per the project constraint). Add the indexes shown in research (tenant indexes, plant+time composite indexes on event/reading tables). Export every table as a named export so `src/db/index.ts` and `src/db/seed.ts` can import them.

Add a `role` TypeScript union export for reuse:
```typescript
export type UserRole = 'operator' | 'produksjonsleder' | 'admin' | 'system_admin'
```
and apply it via `.$type<UserRole>()` on the users.role column.

  </verify>
  <done>schema.ts defines all nine tables with tenant scoping, timestamp/boolean integer modes, indexes, and a UserRole export; src/db/index.ts type-checks.</done>
